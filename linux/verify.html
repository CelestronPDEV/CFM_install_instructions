Security & Verification

Before installing, please verify that the Celestron Firmware Manager you downloaded is authentic. We use GPG (GNU Privacy Guard) to sign our official packages.

1. Initial Setup (One-time only)

To verify our software, you must first import the Celestron public signing key to your local keyring. You only need to do this once.

curl -s https://software.celestron.com/updates/linux/celestron-linux-signing.asc | gpg --import

2. Verify Your Package

Perform this step whenever you download a new update. Navigate to the directory where you extracted the ZIP archive before running these commands.

For Debian / Ubuntu Systems (.deb)

gpg --verify celestronfirmwaremanager_3.0-1_amd64.deb.asc celestronfirmwaremanager_3.0-1_amd64.deb

For RedHat / Fedora / AlmaLinux (.rpm)

gpg --verify celestronfirmwaremanager-3.0-1.x86_64.rpm.asc celestronfirmwaremanager-3.0-1.x86_64.rpm
What the results mean:
• Success: Look for gpg: Good signature from "Celestron...".
• Note: A warning about "not certified with a trusted signature" is normal and expected unless you have manually signed our key.
• Warning: If you see BAD signature, do not run the software and delete the file.
