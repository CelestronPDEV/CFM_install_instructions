Install Celestron Firmware Manager

Before you begin: Ensure you have verified your download signatures at verify.html to ensure the software has not been tampered with.

Please select your Linux distribution family below:

1. Install the Package

Open your terminal in the unzipped folder and run:

sudo apt update && sudo apt install ./celestronfirmwaremanager_3.0-1_amd64.deb

This will automatically install any required dependencies.

2. Configure Permissions

If updating via USB/Serial, add your user to the dialout group:

sudo usermod -aG dialout $USER

You must log out and back in for this to take effect.

1. Install the Package

Open your terminal in the unzipped folder and run:

sudo dnf install ./celestronfirmwaremanager-3.0-1.x86_64.rpm

2. Configure Permissions

If updating via USB/Serial, add your user to the dialout group:

sudo usermod -aG dialout $USER

You must log out and back in for this to take effect.

Updating via WiFi?

No special group permissions (like dialout) are required for WiFi updates. However, ensure that your firewall allows the application to communicate over your local network. If the telescope is not detected, try temporarily disabling your firewall to test the connection.
