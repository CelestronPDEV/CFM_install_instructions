Installation Guide: Windows 10 & 11

Follow these steps to install the Celestron Firmware Manager (CFM) on your Windows PC.

1. Extract the Archive

Right-click the downloaded .zip folder and select Extract All.... Choose a destination folder and click Extract.

2. Run the Installer

Inside the extracted folder, double-click the celestronfirmwaremanager_3.0_x86.msi file.

Note: Windows will automatically verify our digital signature. If you see a security prompt, verify the publisher is Celestron and click Run.

3. Launch CFM

Once installation is complete, you can launch the application from your Start Menu by searching for "Celestron Firmware Manager".

USB Connectivity (Prolific Driver)

If you are connecting to your telescope via a USB port on the hand controller, Windows usually identifies and installs the driver automatically.

Troubleshooting Connection Issues

If CFM cannot find your hand controller after you have plugged it in, you may need the Legacy Prolific Driver (v3.8.x).

Recommended Steps:

  1. Unplug your hand controller from the PC.
  2. Download the version 3.8.x driver from the official Microsoft Update Catalog.
    3. Search Microsoft Catalog
  3. Install the driver.
  4. Reboot your computer to ensure the system initializes the legacy driver correctly.
  5. Plug your hand controller back in and launch CFM.
